# 北京大学信班网站

面向 GitHub Pages 的静态多页面网站，无需安装依赖。

## 页面

- `index.html`：主页，仅包含轮播推送、最新动态、栏目入口和相关院系
- `about.html`：信班介绍与培养方向
- `news.html`：班级动态
- `members.html`：成员年级
- `research.html`：学术研究与实践

## 发布到 GitHub Pages

1. 将本文件夹全部内容上传至 GitHub 仓库。
2. 打开仓库的 **Settings → Pages**。
3. 发布来源选择主分支和根目录。

## 素材与内容说明

网站头部、页脚与浏览器图标使用透明版正式标识 `assets/xin-class-icon.png`。信班活动照片来自北京大学或北京大学信息科学技术学院官网；公开发布前请确认图像使用要求。

新闻与培养信息根据北京大学官方公开资料整理，外链指向原始官方报道。
